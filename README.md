# 📊 Social Media Analytics Project (Excel)
## 📌 Overview

This project is an Excel-based dashboard designed to analyze and visualize social media performance data. It helps track key metrics such as engagement, reach, impressions, and follower growth to support data-driven decision-making.

## 🎯 Objectives

Analyze social media performance across platforms

Track engagement metrics (likes, comments, shares)

Identify trends and top-performing content

Provide insights for improving content strategy

## 🗂️ Dataset

The dataset used in this project includes:

Post Date

Platform (Instagram, Facebook, Twitter, etc.)

Post Type (Image, Video, Reel, etc.)

Likes

Comments

Shares

Impressions

Reach

Engagement Rate

⚙️ Tools & Features Used

Microsoft Excel

Pivot Tables

Pivot Charts

Slicers for interactivity

Conditional Formatting

Data Cleaning & Transformation

Dashboard Design

## 📈 Key Metrics Analyzed

Engagement Rate = (Likes + Comments + Shares) / Reach

Total Posts

Total Engagement

Follower Growth (if included)

Platform-wise Performance

Content Type Performance

## 📊 Dashboard Features

Interactive filters using slicers

Monthly and platform-wise performance trends

Top-performing posts visualization

Engagement comparison across platforms

Clean and user-friendly layout

## 🧹 Data Cleaning Steps

Removed duplicates

Handled missing values

Standardized date formats

Ensured consistent category naming

## 🚀 How to Use

Open the Excel file

Go to the Dashboard sheet

Use slicers to filter by platform, date, or content type

Analyze charts and KPIs

## 📌 Insights (Example)

Video content generates higher engagement than images

Weekends show increased user interaction

Instagram outperforms other platforms in reach
